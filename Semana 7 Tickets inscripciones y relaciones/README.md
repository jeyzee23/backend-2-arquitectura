# Semana 7 — Tickets e inscripciones

Una persona se anota a un evento. El ticket guarda esa relación: quién, a qué evento, cuántos lugares y si la inscripción sigue vigente.

| Carpeta | Qué es |
| --- | --- |
| `meetops-semana7-starter` | Para completar. Los pasos están en `LAB.md`. |
| `meetops-semana7-completa` | El mismo proyecto terminado. |

```bash
cd meetops-semana7-completa
copy .env.example .env
npm install
npm run dev
npm run smoke
```

Sin `MAIL_HOST` o sin `MAIL_PASS`, el mail se imprime en la consola. La inscripción queda igual.

El detalle de rutas y reglas está en `meetops-semana7-completa/README.md`.
