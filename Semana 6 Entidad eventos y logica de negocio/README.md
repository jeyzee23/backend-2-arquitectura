# Semana 6 — Eventos y reglas de negocio

Un evento tiene fecha, cupo, precio y estado. Solo el organizador dueño, o un admin, puede modificarlo. El listado se filtra, se pagina y se ordena.

| Carpeta | Qué es |
| --- | --- |
| `meetops-semana6-starter` | Para completar. Los pasos están en `LAB.md`. |
| `meetops-semana6-completa` | El mismo proyecto terminado. |

```bash
cd meetops-semana6-completa
copy .env.example .env
npm install
npm start
npm run smoke
```
